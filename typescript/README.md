# @quaestor-ledger/pub-lib-core

Transport-neutral, dependency-free TypeScript primitives for untrusted Quaestor
clients. Values are validated and frozen at construction time. They establish
wire-format validity only; services remain responsible for authentication and
product authorization.

See the [repository README](https://github.com/quaestor-ledger/quaestor-pub-lib-core)
for the independent contract authorities, cross-runtime conformance cases, and
publication-boundary guarantees.
